# bandadau-backend

Microservicios de **Bandada U**: identity y events (Spring Boot), wallet y notification (Laravel),
social, media, ticketing, insights y admin-gateway (NestJS). PostgreSQL, MongoDB y DynamoDB;
mensajería con RabbitMQ (CloudEvents), SAGA orquestada, idempotencia y servidor MCP.

Ver [`AGENTS.md`](AGENTS.md) y la documentación en `../bandadau-docs`.
